PricklyMails provides an EU‑hosted real‑time email verification API that checks syntax, MX records, and probes mailboxes via SMTP where allowed. It flags disposable and role addresses, returns honest verdicts, and refunds checks that cannot be completed. The service is billed per verification using a prepaid token wallet, supports OAuth 2.1 PKCE for AI agents, and offers webhooks, batch processing, and rate‑limit controls.

**Areas:** Email Verification · API · SaaS · Data Validation · EU-hosted
